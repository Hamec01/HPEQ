# Integrated Score laboratory

Written before the first integrated effects run. This extends the immutable M0 tool with measurements for new features (M0: n/a). Original M0 signals/events/raw hashes remain unchanged. New state XML is compared semantically: every original parameter retains its value, and appended parameters reset to their defaults.

The standalone Score laboratory uses the production ScoreEngine and its production effects. Synthetic signals have fixed sample positions and a fixed seed. Raw interleaved stereo float captures and CSV measurements are retained under out/score; tracked reports include source and tool identities. Plugin integration, state and allocation tests remain separate.

- Timing: an impulse at 100 ms, unity Forward, no feedback/space/filter, maximum absolute output error against an exactly delayed reference, at 44.1/48/96 kHz. Test free and tempo-synchronised timing.
- Bands: neutral recombination against the unfiltered delay; separately enable each band and measure timing and sinusoidal response. Independently delayed bands need not reconstruct dry.
- Feedback pitch: finite 440 Hz tone, unity or -12 st initial reflection, loop step -12/+12 st. Estimate each isolated round using a Hann FFT and interpolated spectral peak. Inspect leakage/sidebands separately; precision targets retain the original >=500 ms window after 250 ms settling wherever a full-length plateau exists.
- Reverse/glitch: use a non-palindromic ramp, compare each interior fragment against analytically addressed source samples (32-sample fades and Hann overlaps excluded only where documented); verify omission and stutter subdivisions separately.
- Space: each of three characters/routes, finite impulse response, tail energy and channel correlation. After Echo must not inject its spatial tail into feedback; In Feedback must not add a separate direct spatial output.
- Freeze: prime with deterministic signal, engage at 2 s, allow 2 s settling, compare ten consecutive 6 s windows (60 s total), <=1 dB energy spread. Continue to five minutes, checking finite samples and peak bounds. Release, then ensure the retained loop decays rather than disappearing abruptly. Host infinity is checked through the plugin wrapper.
- CPU: Release build, 48 kHz/256, eight distinct pitches with all effects active, one and two prepared engines; wall time for every block, mean <=25%/50%, maximum disclosed. Repeat surprising runs, retaining them. This is followed by complete plugin CPU measurement, not a substitute for it.
- Determinism: all effects and sample-positioned parameter/tempo/mode events, blocks 1/64/127/512/4096 after prepare(256). C++ new/new[]/aligned allocations are counted only around prepared audio callbacks.

Factory calibration methods and identities will be frozen separately after DSP is stable. No provisional renders may be reused across a DSP change.

## Stability correction before calibration

The first two-pole complementary crossover reconstructed neutral bands but could sustain an unwanted oscillation when differently delayed bands reinforced their overlap. The adversarial case uses 500 ms loop time, scales 0.998 / 1.00047 / 1.00183, all feedback=0.9, no space and a single impulse. Its energy grew to 208194 in second 29, peak 6.35, despite the loop safety saturation. Retained in out/score/stability_before. This is a DSP failure, not a changed acceptance threshold.

The correction uses ordered one-pole complementary analysis bands. Their sum is exactly one and sum of squared magnitudes is <=1. Independent delay phases preserve each band's magnitude. A shared return gain bounds sqrt(sum effectiveFeedback_b^2) to 0.9 (Cauchy-Schwarz), including enabled ramps and band gain/pan. Typical moderate settings need no trim. High combined feedback is trimmed; individual controls remain available and the interaction is explained in help. Output/tap EQ keeps its original two-pole filters. Re-run all integrated measurements and calibrate only the corrected production source. No numerical goal is relaxed.

The first combined pitch/Reverse reference failed for all six non-unity intervals (max error 0.138..0.216). Inspection found that the 80 ms compensation for reading a pre-transposed stream had also moved the grain clock. The independent reference correctly kept fragment starts on the requested/effective delay grid. Production now separates the history read offset from the fragment clock: only the former subtracts pitch capture. Reverse, Stutter and Tape Stop retain their full-duration rhythmic grid when a note changes. The original analytic reference and 1e-6 tolerance are unchanged; failed stable_020 captures remain retained.
