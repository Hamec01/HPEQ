HamloRack (beta) - frequency-layer FX, VST3, Windows x64

Install
  1. Close your DAW.
  2. Back up/remove an older HPEQ.vst3 rack bundle, then copy "HamloRack.vst3" to:
       C:\Program Files\Common Files\VST3\
  3. Start the DAW and rescan plugins (FL Studio: Options > Manage plugins > Find more plugins).
  4. HamloRack appears as an effect (manufacturer HamloProd). Insert it on a mixer track.

Uninstall
  Delete C:\Program Files\Common Files\VST3\HamloRack.vst3

Notes
  - VST3 only, Windows 10/11 x64.
  - The plugin is not code-signed yet; Windows may show a warning when you open the zip.
  - The HPEQ plugin ID and old projects are preserved. Do not install both rack versions simultaneously.
  - Native modules use schema 2. Old projects keep schema 1 and the legacy DSP until explicitly upgraded.
  - See RELEASE_NOTES.md for what works, what was measured and the known limitations.
