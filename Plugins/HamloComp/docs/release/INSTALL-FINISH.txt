HamloComp is installed.

1. Open your 64-bit DAW and rescan VST3 plugins.
2. Insert HamloComp (HamloProd) on a track or bus as an effect.
3. Pick a preset from the DAW's program list, or start from Default.

The README is in Start menu -> HamloProd -> HamloComp README,
and in the HamloComp.vst3\Documentation folder.
If Windows asks for a restart, do it before opening your DAW.
