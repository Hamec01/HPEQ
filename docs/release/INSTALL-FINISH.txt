HamloMag is installed.

1. Open your 64-bit DAW and rescan VST3 plugins.
2. Insert HamloMag (HamloProd) on a track, a bus or the master for warmth, weight or grit.
3. Pick a preset on the screen top left (or the DAW's program list), or start from Default.

The README is in Start menu -> HamloProd -> HamloMag README,
and in the HamloMag.vst3\Documentation folder.
If Windows asks for a restart, do it before opening your DAW.
