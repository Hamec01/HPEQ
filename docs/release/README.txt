HamloShirota 0.1.0 - stereo-processor, VST3, Windows x64 (HamloProd)

Controls
  WIDTH        0 % = exact mono, 100 % = unchanged, 200 % = twice as wide.
  STEREOIZE    PROSTOR / KOSMOS: creates stereo from mono; the mono sum stays exactly the same.
  SPACE        KOSMOS: the 'behind / around' colour and a wider side. Strongest on headphones.
  MONO BASS    Everything below this frequency becomes mono (tight low end, club-safe).
  ROTATION     Turns the whole stereo image left or right.
  MODE         EDINSTVO M/S width; PROSTOR stereoize, mono-safe; KOSMOS surround, behind.
  BALANCE      Level of left against right.
  MIX          Blend with the dry signal.
  OUTPUT       Level after the module.
  SAFE         Mono guard: the side never gets louder than the mid, so the mix never cancels in mono. Adds 2.5 ms latency.
  MONO CHECK   Hear the result in mono.
  ON           the lamp switch; off = the dry signal

Presets: the screen top left - the arrows step through the presets (or the mouse wheel; click the name for a menu).
The same presets are in the DAW's program list.

Mono and stereo. The latency is fixed and reported to the DAW.

Uninstall: Settings -> Apps -> HamloShirota, or Start menu -> HamloProd -> Uninstall HamloShirota.
