# QUICK acceptance, before implementation

QUICK is a simplified Note Score controller, not a Legacy blend or a separate audio algorithm. TIME selects free milliseconds or tempo divisions; MOTION adds repeats, pitch movement or captured actions according to the selected move; SPACE adds the existing spatial field. MIX remains explicit, including zero-effect Default. Eight moves: Echo, Tape, Bounce, Note Fall, Note Rise, Reverse, Texture, Cloud. Full Note Score remains available.

Append six parameters after the existing 143 Score parameters. Quick is disabled for old states and all factory recipes. Preserve original parameter metadata/order, programs, shared PresetScreen and Source/DSP. Quick overrides a temporary recipe; entering/leaving it retains the stored detailed score. EDIT IN NOTE SCORE explicitly transfers the effective recipe using canonical parameter conversions. Project state restores macros and the underlying score. Manual source-relative pitch and capture limits remain unchanged.

Acceptance: old DSP and 200 compiled recipes unchanged with Quick disabled; neutral Default bit-identical to dry; all eight moves finite and audible at nonzero Mix; recipe values in declared ranges at zero/mid/max; transfer preserves every effective setting and audio continuation exactly; Quick state round trip; old state disables Quick over an edited instance; block sizes 1/64/127/512/4096 produce bit-identical output at identical event positions; prepared audio allocates no memory including macro changes. Run all existing tests and 160 M0 comparisons. Inspect full/small Quick and existing detailed pages. Run pluginval5..10 and Steinberg, build 0.2.2 installer/ZIP and hash-compare packaged VST3 with the validated build. Installer is prepared, not run; owner FL audition remains a human step.
