# HamloRevolution

A rhythmic multi-effect sequencer of the Hamlo line (HamloProd): SIMPLE mode (genre-aware generation from a few
knobs, CONNECT TO HPDG) and ADVANCED mode (lanes: SLICE / SHAPE / THROW, bands, scenes). Started from HPEQ's
HamloRevolution module.

State: design only - docs/REVOLUTION_V2.md (design, targets V1 .. V14, stages R0 .. R6) and docs/HPDG_LINK.md (the
HPDG <-> plug-in link). The next step is R0 (the M0 extraction), see AGENTS.md.
