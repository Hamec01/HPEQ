HamloEcho is installed.

1. Open your 64-bit DAW and rescan VST3 plugins.
2. Insert HamloEcho (HamloProd) on a track or a bus.
3. Start from Default (dry, zero effect) or pick a genre preset on the screen top left.
   Default is under Factory / General. Raise Mix and Time to begin adding echoes.

The README is in Start menu -> HamloProd -> HamloEcho README,
and in the HamloEcho.vst3\Documentation folder, together with USER-GUIDE.txt.
If Windows asks for a restart, do it before opening your DAW.
