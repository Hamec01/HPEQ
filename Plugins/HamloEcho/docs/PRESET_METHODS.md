# Echo factory library calibration and independent verification

Written before calibration. There are 200 new recipes, with the approved category allocation in each of Boom Bap / Trap / Techno / DnB. Original host programs 0..7 retain their positions; new programs are 8..207. Tools/score_presets.py contains named musical recipes and explicit genre profiles, not random values. Notes are intervals from manual FL C5 (MIDI 60); samples and evolving melodies retain their original musical motion.

Use the owner's named WAVs at 48 kHz, an energetic ten-second excerpt (or the whole shorter file), normalised to -18 dBFS RMS with a -3 dBFS sample-peak ceiling. The peak ceiling takes precedence over RMS. Track the original SHA256, exact excerpt position, conversion and final prepared WAV SHA256. All full renders include the declared tail; check energy in their final second to detect truncation.

Depth is 10 log10(wet energy / prepared dry-source energy), integrating the full render including tail. The Insert wet component is recovered independently as actual Insert output minus (1-Mix)*dry. Send is a separate actual render and must equal the expected unscaled wet branch within float rounding. Both depth measurements must lie in the recipe's stated band: Gentle [-24,-16), Medium [-16,-8), Heavy [-8,+6] dB.

All recipes start at Mix=0.5. Thus Send depth exceeds Insert-wet depth by 6.0206 dB. Calibrate Wet Output at the midpoint of the intersection that satisfies BOTH routing ranges: Insert targets -23.0103 / -15.0103 / -4.0103 dB respectively. Mix and Wet Output are excluded from uniqueness. This policy does not equate Insert and Send or silently change Mix on routing switches.

First render an uncalibrated Send with Wet Output=0. Derive its required constant wet gain from the measured energy, then independently render both routings with that gain. Wet Output is after the feedback loop and does not alter its sound; this gain is linear. If the required gain exceeds its public range, report a failure and revise the authored recipe instead of clamping a failed calibration to a passing label.

Resume keys include compiled production source ID, laboratory executable SHA256, recipe fingerprint, prepared-material SHA256, tempo and method version. Reject stale identities rather than reusing their measurements. Save a completed result only after its files and checks are written; interrupted jobs are rerun. Calibration and compiled-bank verification are separate passes. A stored scalar is not proof that its compiled preset produces it.

For each compiled program, check metadata, complete state round-trip (all parameters and selected program), finite samples, both depth ranges, reconstruction error, stereo correlation/mono loss, final-tail energy and uniqueness across the complete bank excluding Mix/Output. Prepared A/B demonstrations receive a single common scale across dry/Insert/Send to keep every demo <=-1 dBTP measured by an 8x polyphase true-peak estimate; disclose that demonstration scale. Also report unscaled plugin output peaks. This is an Echo, not an output limiter.
